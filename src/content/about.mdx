### 문서 제출 프로세스

<Steps>
{<h3>브랜치 생성</h3>}
main 브랜치에서 새 작업 브랜치를 생성합니다.
```bash
git checkout -b feature/[주제]-[챕터]-[이름]
```

{<h3>문서 작성</h3>}

마크다운 또는 MDX 형식으로 내용을 정리합니다.

```
# 제목: [주제] - [챕터명]

## 개요
...
```

{<h3>커밋 및 푸시</h3>}

변경사항을 커밋하고 원격 저장소에 푸시합니다.

```bash
git add .
git commit -m "Add: [주제] [챕터] 정리"
git push origin feature/[주제]-[챕터]-[이름]
```

{<h3>PR 생성</h3>}

GitHub에서 Pull Request를 생성하고 리뷰를 요청합니다.

</Steps>

    - **체계성**: 논리적인 순서로 내용을 구성

      - ...

      ## [섹션1]

    </div>

  </Tabs.Tab>
  <Tabs.Tab>
    ### 작성 방법

    <Steps>
      ### 문서 생성 명령어 실행
      터미널에서 `yarn create-docs` 명령어를 실행합니다.

      ### 책/주제 선택
      방향키로 원하는 책이나 주제를 선택하고 Enter를 누릅니다.

      ### 챕터명 입력
      작성할 챕터의 이름을 입력하고 Enter를 누릅니다.

      ### 템플릿 기반 작성
      생성된 템플릿 파일을 열고 내용을 작성합니다.
    </Steps>

    <Callout type="warning" emoji="⚠️">
      문서는 마감 기한(화요일 23:59:59)까지 반드시 제출해야 합니다.
    </Callout>

  </Tabs.Tab>
</Tabs>

## 참여 규칙

<Callout type="info">
  TechDigest는 모든 참여자의 적극적인 참여와 기여를 바탕으로 운영됩니다.
</Callout>

- **적극적 참여**: 모든 미팅에 참석하고 질문과 토론에 적극 참여
- **상호 존중**: 다양한 의견과 관점을 존중하는 태도 유지
- **지식 공유**: 개인이 습득한 지식을 팀원들과 공유
- **책임감**: 정해진 일정과 제출 기한 준수
