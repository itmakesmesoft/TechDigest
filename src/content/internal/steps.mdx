# Steps

번호가 매겨진 목록을 시각적인 단계 표현으로 바꿔주는 컴포넌트

## Preview

<Steps>
{<h3>첫 번째 단계</h3>}

첫 번째 단계에 대한 설명

{<h3>두 번째 단계</h3>}

두 번째 단계에 대한 설명

{<h3>세 번째 단계</h3>}

세 번째 단계에 대한 설명

</Steps>

## 사용법

Markdown 제목 (`<h2>`부터 `<h6>`까지) 세트를 `<Steps>` 컴포넌트로 감싸 시각적인 단계로 표시합니다. 페이지의 콘텐츠 계층 구조에 따라 적절한 제목 수준을 선택할 수 있습니다.

```mdx
import { Steps } from "nextra/components";

## 시작하기

여기에 대한 설명이 있습니다.

<Steps>
### 1단계

1단계 내용

### 2단계

2단계 내용

</Steps>
```

### 목차에서 제목 제외하기

`<Steps>` 컴포넌트 (또는 다른 제목)의 제목이 목차에 나타나지 않도록 하려면 제목 `### ...`을 다음과 같이 중괄호`{}`로 묶어줍니다.

```mdx
<Steps>
- ### 1단계
+ {<h3>1단계</h3>}

1단계 내용

</Steps>
```

## API

| 이름       | 타입                             | 기본값 | 설명                                             |
| :--------- | :------------------------------- | :----- | :----------------------------------------------- |
| `...props` | `HTMLAttributes<HTMLDivElement>` |        | 기본 `<div>` 요소의 모든 HTML 속성을 지원합니다. |
