import { Bleed } from "nextra/components";

# Bleed

컨테이너의 너비보다 약간 더 넓게 콘텐츠를 확장하는 컴포넌트

## Preview

<Bleed>내부에서 **Markdown** 문법을 사용할 수 있습니다.</Bleed>

<Bleed full>
  <iframe src="https://www.google.com" width="100%" height="500px" />
</Bleed>

## 사용법

**MDX**

```mdx
import { Bleed } from "nextra/components";

<Bleed>내부에서 **Markdown** 문법을 사용할 수 있습니다.</Bleed>

<Bleed full>[google](https://www.google.com)</Bleed>

<Bleed full>
  <iframe src="https://www.google.com" width="100%" height="500px" />
</Bleed>
```

## API

| 이름       | 타입                             | 기본값 | 설명                                             |
| :--------- | :------------------------------- | :----- | :----------------------------------------------- |
| `full`     | `boolean`                        |        | 콘텐츠를 컨테이너의 가장자리까지 확장합니다.     |
| `...props` | `HTMLAttributes<HTMLDivElement>` |        | 기본 `<div>` 요소의 모든 HTML 속성을 지원합니다. |
